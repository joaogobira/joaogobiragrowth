## 1. CHECKLIST DE QUALIFICAÇÃO DE VAGA ✅ (IR OU NÃO IR)

> Use este checklist antes de se candidatar. Se ≥ 6 pontos: **candidate-se**. Se < 4: **pule**.

| # | Critério | Sim ✓ | Não ✗ |
|---|----------|--------|--------|
| 1 | O título da vaga bate com pelo menos um dos seus 3 perfis (SEO / CRM / Performance)? | | |
| 2 | A vaga menciona pelo menos 2 ferramentas que você domina? | | |
| 3 | O nível pedido é Sênior, Especialista ou Coordenador (não Pleno/Júnior)? | | |
| 4 | O segmento da empresa está entre: saúde, edtech, e-commerce, SaaS, fintech ou agência? | | |
| 5 | A empresa tem mais de 50 funcionários (indicador de estrutura de Growth)? | | |
| 6 | A vaga tem pelo menos 1 resultado mensurável pedido (ex: "gerir ROAS", "aumentar tráfego")? | | |
| 7 | Localização é remota, híbrida ou dentro de 60km de SJC? | | |
| 8 | A descrição NÃO pede habilidade crítica que você não tem (ex: gestão de 10+ pessoas)? | | |
| 9 | A empresa tem presença real no LinkedIn com conteúdo recente? | | |
| 10 | A vaga tem menos de 15 dias de publicação? | | |

**Pontuação: _____ / 10**
- **8-10** → Prioridade ALTA — adapte CV + escreva carta personalizada
- **6-7** → Prioridade MÉDIA — use CV padrão + aplique rápido
- **< 6** → Considere pular ou enviar sem adaptação

## 3. ATS HACK — COMO ESPELHAR PALAVRAS-CHAVE DA VAGA NO CV

> O ATS (sistema automático de triagem) cruza palavras-chave da vaga com seu CV. Se não tiver correspondência: reprovado antes de humano ver.

### Passo a Passo (5 minutos)

**1. Extraia as palavras-chave da vaga**
Cole a descrição da vaga no [ChatGPT](https://chat.openai.com) e peça:
> _"Liste as 15 palavras-chave técnicas mais importantes dessa descrição de vaga para um profissional de marketing digital"_

**2. Verifique quais já estão no seu CV**
Abra o HTML do CV e use `Ctrl+F` para verificar cada palavra.

**3. Insira as que faltam**
Locais seguros para inserir sem forçar:
- Resumo/Summary (primeiro parágrafo)
- Badges/Skills no topo
- Bullet points das experiências (troque termos equivalentes)

**4. Regra de ouro**
Nunca copie a frase inteira da vaga. Use a palavra-chave em contexto natural.

| Palavra-chave da vaga | Como inserir no CV |
|----------------------|-------------------|
| "Marketing Automation" | "...configurei fluxos de Marketing Automation no HubSpot..." |
| "Tráfego Orgânico" | "...escalei tráfego orgânico de 600K para 900K..." |
| "Growth Hacking" | "...apliquei táticas de Growth Hacking para reduzir CPL..." |
| "Data-driven" | "...tomada de decisão data-driven via GA4 e Looker Studio..." |

## 4. ROTEIRO PARA ADAPTAR BULLET POINTS EM 15 MINUTOS

> Use este roteiro quando a vaga for prioridade ALTA (8-10 pontos no checklist).

### Estrutura do bullet point ideal
```
[Ação forte] + [O que foi feito] + [Resultado mensurável] + [Ferramenta/Contexto]
```

**Exemplos de verbos de ação fortes (escolha por tipo de vaga):**

| SEO / CRO | CRM / Retenção | Performance |
|-----------|---------------|-------------|
| Auditou | Construiu | Gerenciou |
| Otimizou | Configurou | Escalou |
| Estruturou | Segmentou | Reduziu |
| Implementou | Automatizou | Aumentou |
| Corrigiu | Ativou | Implementou |

### Checklist de adaptação rápida
- [ ] Resumo menciona o nome do cargo da vaga?
- [ ] Pelo menos 3 bullet points usam palavras-chave da vaga?
- [ ] As métricas de maior impacto para esse tipo de vaga estão nas primeiras linhas?
- [ ] Ferramentas pedidas na vaga aparecem ao menos 2x no CV?
- [ ] O cargo do último emprego está adaptado para buscabilidade?
